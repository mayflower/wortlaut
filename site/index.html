SO FUNKTIONIERT’S

In drei einfachen Schritten vom Gespräch zum fertigen Protokoll

Keine komplizierte Einrichtung für Teilnehmende, keine Browser-Plugins und kein manuelles Mitschreiben.

01

1. Termin verbinden oder Link einfügen

Verknüpfe einmalig deinen Google- oder Microsoft-365-Kalender, leite eine Termineinladung per E-Mail weiter oder füge spontan den Link eines laufenden Meetings in der Web-Oberfläche ein.

02

2. Entspannt sprechen

wortlaut tritt dem Meeting als rein passiver Audio-Zuhörer bei, stellt sich im Konferenz-Chat transparent mit dem Namen der einladenden Person vor und erfasst jeden Redebeitrag getrennt nach Sprecher.

03

3. Nachlesen, suchen & teilen

Direkt nach Gesprächsende erhältst du das fertige Wortprotokoll per E-Mail und in der Web-Oberfläche. Durchsuche alle Gespräche im Volltext, teile einen geschützten Lese-Link mit dem Team oder exportiere den Text.

Klare Sprecherzuordnung – ganz ohne biometrische Stimmprofile

Herkömmliche Cloud-Dienste mischen alle Stimmen zusammen und versuchen nachträglich per Stimmprofil zu erraten, wer gesprochen hat. wortlaut geht einen besseren Weg:

  • ✓Jede Tonspur wird bereits während der Konferenz getrennt erfasst und direkt dem jeweiligen Teilnehmernamen im Meeting zugeordnet.
  • ✓Auch wenn mehrere Personen kurz gleichzeitig sprechen oder sich ins Wort fallen, bleiben die Aussagen sauber getrennt.
  • ✓Es werden keinerlei biometrische Stimmprofile (Voiceprints) angelegt oder gespeichert.

DATENSCHUTZ & VERTRAUEN

Gebaut für vertrauliche Gespräche und strenge Datenschutz-Anforderungen

Warum Unternehmen, Kanzleien, Beratungen und öffentliche Auftraggeber wortlaut statt kommerzieller US-Cloud-Bots einsetzen.

100 % auf euren eigenen Servern

Sowohl die Gesprächsannahme als auch die Spracherkennung laufen vollständig in eurem eigenen Cluster. Keine einzige Sekunde Audio wird an externe Cloud-Anbieter übertragen.

Transparent & respektvoll im Meeting

wortlaut zeichnet niemals Kamerabilder oder Bildschirminhalte auf. Beim Beitritt stellt sich der Bot im Chat mit dem Namen der einladenden Person und einem Link zur öffentlichen Datenschutz-Erklärung vor.

Automatische Löschfristen & 1-Klick-Löschung

Roh-Audiodaten werden nach 24 Stunden automatisch gelöscht, schriftliche Protokolle nach 30 Tagen. Vertrauliche Besprechungen lassen sich zudem jederzeit sofort mit einem Klick restlos entfernen.

Mandantentrennung & Single Sign-On

Über Single Sign-On (OIDC) sieht jede Person standardmäßig nur ihre eigenen Aufnahmen und Kalendereinträge – geschützt vor unbefugtem Zugriff.

SELBST HOSTEN (OPEN SOURCE)

In wenigen Minuten auf dem eigenen Server oder Cluster starten

wortlaut ist freie Software unter der GNU AGPLv3. Starte das System per Docker Compose auf einem einzelnen Server, per Helm Chart in Kubernetes oder direkt lokal zur Evaluierung. 

# 1. Repository klonen
git clone https://github.com/mayflower/wortlaut.git
cd wortlaut

# 2. Kompletten Stack (inkl. Postgres, MinIO & CPU-Fallback) starten
docker compose up -d --build

# Web-Oberfläche:  http://127.0.0.1:8000/ui
# API-Übersicht:   http://127.0.0.1:8000/docs
# Installation im Kubernetes-Cluster per Helm Chart
helm install wortlaut ./charts/wortlaut \
  --namespace wortlaut \
  --create-namespace \
  --set config.apiUrl=https://wortlaut.example.org/ \
  --set config.sdkPageUrl=https://wortlaut.example.org/sdk/ \
  --set secrets.apiToken="$WORTLAUT_API_TOKEN" \
  --set secrets.databaseUrl="$DATABASE_URL"
# Option A: Direkt lokal auf Linux starten (ohne Kubernetes)
./scripts/run-local.sh

# Option B: Deklarativ per Kustomize in Kubernetes ausrollen
kubectl apply -k deploy/k8s/base

# Option C: Lokale Entwicklungsumgebung mit Tilt
make setup && make dev

Was du für den Betrieb brauchst

  • ✓Flexibles Deployment: Docker Compose (Einzelserver/VM), Kubernetes (Helm Chart oder Kustomize) oder direkt lokal
  • ✓Spracherkennung: NVIDIA-GPU empfohlen für Echtzeit-Betrieb – dank CPU-Fallback auch ohne GPU test- und nutzbar
  • ✓PostgreSQL-Datenbank & S3-Speicher (bei Docker Compose bereits mit MinIO vorkonfiguriert)
  • ✓Optional: Single Sign-On (OIDC), E-Mail-Versand (SMTP/IMAP) & Kalender-Sync für Google Workspace / Microsoft 365
