# src

## Overview
Python source root directory containing the `wortlaut` application package for the meeting service.

## Subdirectories & Boundaries
- `wortlaut`: [./wortlaut/README.md](./wortlaut/README.md) - Core Python package implementing the FastAPI meeting coordination API, PostgreSQL models, S3 audio storage, per-source WebRTC VAD segmentation, GPU ASR job orchestration, Kubernetes worker controller, and IMAP/SMTP calendar and delivery pipelines.
